# Support and error reporting

Before filing a report:

1. Back up the current document with **More → Download complete document**.
2. Close older editor tabs and reproduce with the latest release.
3. Record the browser and operating-system versions.
4. Note whether the editor was opened from HTTPS, localhost or `file://`.
5. For import/export errors, use a minimal sample with private content removed.

Open a bug report at:

<https://github.com/shynloc/ACKS-Markdown-Editor/issues/new?template=bug_report.yml>

Never include API keys, access tokens, private documents or personal data in a
public issue. Security reports belong in GitHub Private Vulnerability Reporting.
